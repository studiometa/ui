# Guide

Learn how `@studiometa/ui` combines server-rendered markup, declarative JavaScript behavior and composable public APIs.

## Start here

1. Read the [Concepts overview](./concepts/) for the library's mental model and vocabulary.
2. Follow [Installation](./installation/) for NPM, Composer, Twig and icon setup.
3. Use the [Usage quickstart](./usage/) to register JavaScript components and render templates.
4. Browse the [Reference](/reference/) when you need an exact component, primitive, decorator, helper or type contract.

## Concepts

- [Packages and surfaces](./concepts/packages-and-surfaces.md) — packages, runtime formats, imports and styling ownership.
- [Declarative runtime](./concepts/declarative-runtime.md) — registration, data attributes, refs, events and lifecycle.
- [Composition](./concepts/composition.md) — components, primitives, decorators, helpers and families.
- [Templates and customization](./concepts/templates-and-customization.md) — Twig parameters, namespaces, overrides and styling.
