# SliderCount

Displays the current index of the slider and updates it on change.

## Refs

### `current`

- Type: `HTMLElement`

Receives the current slide number, one-based: index `0` renders as `1`.

### `total`

- Type: `HTMLElement`

Optional. Receives the total number of slides. Omit it to render a static total in the markup, as the examples do.
