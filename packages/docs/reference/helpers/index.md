# Helpers and utilities

Supported plain functions that help compose or operate the library. Internal family utilities are intentionally excluded unless they are part of the supported public API.

::: info No helpers in v2
`@studiometa/ui` v2 exposes no standalone helper function of its own. `viewTransition`, which v1 published from `@studiometa/ui/scheduler`, now belongs to [`@studiometa/js-toolkit`](https://js-toolkit-v4.studiometa.dev) and is imported from there. Reusable behavior applied to a class is documented under [Decorators](/reference/decorators/).
:::
